Projects

  1. AI Research Assistant (RAG-based)

    Tech Stack: Python, LangChain, ChromaDB, OpenAI, FastAPI

    A Retrieval-Augmented Generation (RAG) assistant designed to help users query and extract insights from large technical document collections. Built over 1,000+ technical documents using LangChain and ChromaDB, the system leverages semantic search and vector embeddings to reduce information retrieval time by 80%. It supports conversational memory and citation-aware responses, and has served 500+ user queries. I exposed the assistant's functionality through REST APIs built with FastAPI for scalable integration with external applications.

  2. Supply Chain Data Quality & Anomaly Detection Pipeline

    Tech Stack: Python, Pandas, NumPy, PostgreSQL, SQLAlchemy, Streamlit, Plotly

    A production-grade data quality system for logistics operations that ingests container shipment data, validates it against a rules engine, detects anomalies with root-cause explanations, and surfaces insights through a live Streamlit dashboard. The pipeline chunks and idempotently loads CSV data into PostgreSQL, then applies 7 anomaly detection rules — covering issues like date inconsistencies, invalid delay predictions, missing fields, and duplicate records — each mapped to a likely root cause and severity level. A QA runner orchestrates the full flow end-to-end, auto-generating Markdown quality reports and flagged-record exports, while the Streamlit dashboard provides four live panels for tracking quality trends, anomaly breakdowns, delay patterns, and filterable flagged records.

  3. Autonomous Document Agent

    Tech Stack: Python, FastAPI, Groq (LLaMA 3), Docs

    An autonomous AI agent built with FastAPI and Groq (LLaMA 3) that takes a natural-language request, independently plans its own execution, gathers relevant data through tool calls, and generates a polished Microsoft Word document — all without a hardcoded pipeline. The agent uses a Planner-Executor architecture: the Planner creates an ordered task list and self-critiques it in a second LLM pass to catch logical gaps before execution begins, while the Executor dispatches tool calls (research, company data, financial projections, industry benchmarks) and builds the document outline. I implemented retry-and-fallback logic across LLM calls and tool invocations, along with request validation guardrails, to make the system resilient and production-ready. The result is a genuinely autonomous agent — it reasons about what information it actually needs for each specific request, rather than following the same fixed steps every time.
